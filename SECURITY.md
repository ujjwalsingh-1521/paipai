# Security

PaiPai reads payment notifications, so security issues matter.

If you find a vulnerability (for example, a way for another app to read PaiPai's data or trigger its actions), please **don't open a public issue**. Report it privately through **[Security → Report a vulnerability](../../security/advisories/new)** on this repo. You'll get a reply as soon as possible, and credit in the fix if you want it.

Only APKs from this repo's [Releases](../../releases) are official. They're signed with one key; Android refuses to update an installed PaiPai with an APK signed by anyone else.
